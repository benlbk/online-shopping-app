# Design: Build an online shopping platform (like Shopee) with full production capabilitie

## Architecture

### Components
- **ProductCatalog** (service): Manages product listings, categories, and search
- **ShoppingCart** (service): Handles cart operations and checkout process
- **PaymentService** (service): Processes payments and handles payment gateway integration
- **UserManagement** (service): Handles user authentication, profiles and addresses
- **OrderManagement** (service): Processes and tracks orders
- **ProductCard** (component): Reusable product display component
- **SearchBar** (component): Product search component with filters


### API Contracts
- `GET /api/products` — List products with pagination and filters
- `POST /api/cart/items` — Add item to cart
- `POST /api/orders` — Create new order


### Data Flow
1. Client sends request to API gateway
2. API routes to appropriate service
3. Service processes business logic
4. Data persisted to database
5. Response returned to client

## Technology Stack
- Frontend: Next.js 14+ with TypeScript, React, Tailwind CSS
- Backend: ASP.NET Core 8+ with C#, Entity Framework Core
- Database: PostgreSQL
- Infrastructure: AWS EKS, Terraform

## Security Considerations
- Input validation on all endpoints
- Authentication via JWT tokens
- Rate limiting on public APIs
- Encrypted data at rest and in transit
